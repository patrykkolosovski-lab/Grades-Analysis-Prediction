# Grade Dashboard

JavaFX dashboard for exploring student grade data and predicting grades with a random-forest model.

## Features

- Data analysis views for current and graduate datasets
- Feature filters and multiple plot types
- Grade prediction for an individual student and subject
- MSE evaluation on a deterministic holdout split

## Stack

Java 24, JavaFX, Maven

## Run

```bash
mvn javafx:run
```

## Test

```bash
mvn test
```

## Data

Bundled CSV files live in `src/main/resources/`.
